# Dota Dungeon: Telegram-игра

Групповая игра на **2–6 участников** по правилам классического «Манчкина» с картами в теме Dota 2. [Спецификация](docs/superpowers/specs/2026-09-24-dota-munchkin-telegram-design.md) описывает общий чат, личные меню и устройство партии.

## Начало игры

1. Добавьте бота в группу и отправьте `/newgame`.
2. Участники нажимают «Войти», открывают личку бота через `/start` и нажимают «Готов» в группе.
3. Ведущий нажимает «Начать». Выбор героя в лобби не требуется: персонаж складывается из полученных карт.

Двери, бой, помощь, вмешательство и результаты видны в группе. Рука, экипировка, цены вещей, профили и обмен доступны в личке. `/game` обновляет меню; `/pause` и `/resume` управляют паузой; `/endgame` завершает партию после подтверждения ведущего.

## Возможности

- Полная базовая колода: **168 физических карт, 147 уникальных**, 95 Дверей и 73 Сокровища. Цены и механика сохранены, названия и изображения относятся к Dota 2.
- Классы, расы, ограничения вещей, способности, продажа за уровни и обмен открытыми вещами. Отдельного золотого кошелька в классических правилах нет.
- Бой с несколькими противниками, помощь, окно реакции, побег, проклятия, выбор потерь, смерть, разграбление и возрождение.
- Личные решения об отмене проклятия, своём кубике и воскрешении сокровищ; обязательную потерю карт выбирает сам участник.
- Много групп с изолированными партиями. PostgreSQL сохраняет состояние, случайность, кнопки, таймеры и очередь сообщений.
- Изображения из проверенного каталога публикаций Valve с указанием источников. [Аудит правил](docs/superpowers/catalogs/classic-dota-v1-audit.md), [поведенческие проверки](docs/superpowers/catalogs/classic-dota-v1-behavior-coverage.md), [аудит изображений](docs/superpowers/catalogs/classic-dota-v1-media-audit.md) и [условия использования](docs/artwork-usage.md).

## Разработка и проверка

Требуется Python 3.12. Установка и локальные тесты:

```powershell
python -m pip install -e ".[test]"
python -m pytest -q
python -m dota_dungeon.cards validate
```

Для интеграционных тестов задайте `TEST_DATABASE_URL` отдельной тестовой базы PostgreSQL. Каждый тест создаёт и удаляет свою схему; без этой переменной PostgreSQL-тесты пропускаются.

Основной интерфейс движка — `dota_dungeon.core.engine.decide(state, command, catalog, rng)`. Время, пользователь, чат и версия кнопки проверяются адаптером. Скрытые карты направляются только владельцу; после смерти содержимое трупа становится открытым по правилам разграбления.

## Запуск

Служба запускается командой `python -m dota_dungeon.service` с переменными `BOT_TOKEN` и `DATABASE_URL`. Образец конфигурации — `deploy/env.example`, служба systemd — `deploy/telegram-dota-dungeon.service`. Ключи не входят в репозиторий.

[Инструкция по запуску и обслуживанию](docs/operations.md) описывает таймеры, сохранение, обновления и проверку сервера. Проверка работающей службы и игровая приёмка двумя людьми — отдельные проверки.
