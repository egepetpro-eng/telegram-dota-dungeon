# Dota Dungeon: игровой движок

Это первая поставка Telegram-игры по [согласованной спецификации](docs/superpowers/specs/2026-09-24-dota-munchkin-telegram-design.md). Чистый Python-движок ведёт партию на 2–6 игроков и не зависит от Telegram или базы данных.

## Что работает

- Лобби, готовность, раздача 4 дверей и 4 сокровищ, ход и милостыня.
- Розыгрыш класса и расы из руки, экипировка, стоимость вещей, продажа за уровни и обмен открытыми вещами.
- Бой, помощь, вмешательство, окно реакции, награды, побег, плохие исходы, смерть и возрождение.
- Изоляция состояния одной партии, события с публичной или личной видимостью и защита от повторного `request_id`.

Основной интерфейс — `dota_dungeon.core.engine.decide(state, command, catalog, rng)`. Пример сценария от лобби до победы находится в `tests/test_simulation.py`.

## Проверка

Требуется Python 3.12 и pytest 8:

```powershell
python -m pip install -e ".[test]"
python -m pytest -q
```

## Следующие поставки

Тематический каталог всех 168 карт Dota 2, Telegram-бот, постоянное хранилище, таймеры и проверка прав на изображения пока не реализованы. Публичный запуск требует этих частей и проверки всех приёмочных сценариев спецификации.

При подключении адаптера `now` в командах обмена и окна реакции должен приходить от сервера. Скрытые карты направляются только в события `user:<id>` или личные события активного игрока; групповые события нельзя дополнять содержимым руки.
